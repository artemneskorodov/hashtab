◆ _OPTIMIZE_SEARCH

#define _OPTIMIZE_SEARCH

Enables optimization of list_search_default().

Note
Optimization helps to avoid saving YMM register value in memory before calling string comparison function.

◆ _OPTIMIZE_STRCMP

#define _OPTIMIZE_STRCMP

Enables optimization of strcmp().

Note
Optimization uses comparison of YMM register. It can be used if your processor supports SSE 4.2. See function cmp_key_optimized() for more info.

Macro to call list search function.

Parameters
_bucketbucket_t * - Pointer to bucket that stores linked list with value to search.
_keyconst char * - Pointer to keyword, that must be 32 bytes long.
_resultdata_t ** - Result of search is written to this pointer.
Note
Calls list_search_optimized() if optimization is enabled and list_search_default() if not.
